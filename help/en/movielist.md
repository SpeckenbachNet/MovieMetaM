# Movie List

The list on the left holds the movies you are editing. Each entry shows the title and the file name below it. If a movie has no title yet, the file name without its extension is shown instead.

## Adding movies

- Click **+** below the list and choose one or more files, or
- drag files from your file manager into the list.

For now **MP4 and M4V files** are supported. Other files are skipped; a short message tells you how many. A movie that is already in the list is not added again.

## Selecting

A click selects a movie; its data appears in the middle under **Movie Info**. Hold Ctrl (Mac: Cmd) or Shift to select several movies, for example to remove them together.

## Status

The symbol in front of each movie shows its status:

- **Green square** – unchanged, the data matches the file.
- **Yellow dot** – changed, not saved yet.

Rest the mouse on an entry to see the full path of the file and its status. How to save is explained under **Saving**.

## Removing

**−** below the list takes the selected movies out of the list.

> The files themselves stay on the disk, untouched.

If one of the movies has unsaved changes, MovieMetaM asks:

- **Save and remove** – saves the changed movies first, then removes all selected ones.
- **Remove** – removes them; the changes are lost.
- **Cancel** – leaves everything as it is.
