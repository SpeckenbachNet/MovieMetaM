# Settings

Open the settings with the gear in the toolbar. **Save settings** applies your changes; the button is only active when you changed something. **Back** returns to the main window.

## Language

The language of MovieMetaM. A change takes effect after a restart.

## Movie data language

MovieMetaM asks TMDB in this language: the genre list, the search, titles and descriptions of the hits, and the posters (posters in this language, in English and without text). This takes effect at once, no restart needed. The movie data language can differ from the app's language: someone who uses MovieMetaM in English can still get Japanese movie data.

If you choose nothing, both languages follow the system.

## Age Rating

The country whose age rating system MovieMetaM uses. The preview shows the steps as badges.

This only applies to movies that have no age rating in the saved file yet. If a file already has one, the movie keeps its system (see **Movie Info** and **Movie Search**). A change takes effect at once and is applied to the movie shown right away.

## Saving

**Safe saving** writes the data into a copy, checks it, and only then replaces the file. This is safer, but needs room and more time. What exactly happens is explained under **Saving**.
