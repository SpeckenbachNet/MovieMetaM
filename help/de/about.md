# MovieMetaM

Version {{version}} · Qt {{qt}}

Editor für die Metadaten von Filmdateien: Titel, Besetzung, Regie, Beschreibung, Genre, Altersfreigabe und Cover – mit Filmdaten aus The Movie Database (TMDB).
