# MovieMetaM

Versión {{version}} · Qt {{qt}}

Editor de los metadatos de archivos de películas: título, reparto, directores, descripción, género, clasificación por edades y carátula, con datos de películas de The Movie Database (TMDB).

## Datos de películas

![The Movie Database](:/images/tmdb.svg)

MovieMetaM encuentra los datos de películas con la API de [The Movie Database (TMDB)](https://www.themoviedb.org). Este producto usa la API de TMDB, pero no está respaldado ni certificado por TMDB.
