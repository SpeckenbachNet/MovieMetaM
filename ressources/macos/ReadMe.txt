MovieMetaM {{version}}
======================

ENGLISH

Requires macOS {{macos}} or later (Apple silicon and Intel).

Install
Drag "MovieMetaM" onto the "Applications" folder next to it.

First start
MovieMetaM is not signed by Apple, so on the first start macOS says it
cannot open the app. To allow it once:
1. Close the message ("Done" or "OK").
2. Open System Settings → Privacy & Security.
3. Next to the note about MovieMetaM at the bottom, click "Open Anyway"
   and confirm (with your password if asked).
After that MovieMetaM starts normally.

Help: in the app via the question mark

DEUTSCH

Benötigt macOS {{macos}} oder neuer (Apple silicon und Intel).

Installieren
Zieh „MovieMetaM“ auf den Ordner „Programme“ daneben.

Erster Start
MovieMetaM ist nicht von Apple signiert. Beim ersten Start meldet macOS
deshalb, dass die App nicht geöffnet werden kann. So erlaubst du sie einmalig:
1. Schließ die Meldung („Fertig“ bzw. „OK“).
2. Öffne Systemeinstellungen → Datenschutz & Sicherheit.
3. Klick unten neben dem Hinweis zu MovieMetaM auf „Dennoch öffnen“
   und bestätige (ggf. mit deinem Passwort).
Danach startet MovieMetaM ganz normal.

Hilfe: in der App über das Fragezeichen
Website: https://software.speckenbach.net/de/moviemetam
Übersetzen helfen: https://software.speckenbach.net/de/moviemetam/translation
